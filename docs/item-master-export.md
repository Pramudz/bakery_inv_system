# Product Master CSV export

The existing Product Master action opens a scope, price list and location dialog. Both scopes use the same 24 columns. Search, status and category filters apply to the complete matching result, not the visible page. The server reads batches of 500 products in SKU order under a repeatable-read transaction and streams UTF-8 CSV with a byte-order mark. Export is read-only.

`PRODUCT_VIEW` and `PRODUCT_MASTER_COST_EXPORT` are both required. Tenant Master also requires a tenant-wide role. Location Master requires an active tenant location assigned to a location-scoped role. The new permission is added to the Product authorization catalog and can be assigned through tenant role permissions; existing cashier roles receive no grant. Users should sign in again after a grant so the Product Master action appears in their session permissions.

Current selling price follows the active selected price list, its currency, the active base sales unit, effective time and quantity tier for one unit. Its active item discount is reported separately; bill discounts are unrelated. Purchase price uses the active primary supplier's active default purchase unit and its current price for one purchase unit in the selected list currency. If several units are eligible, the default wins, then the lowest supplier-unit ID. Current price ties use the largest eligible quantity tier, latest effective start, then largest price ID. Case size is the product-unit conversion factor in base units per purchase unit.

Tenant WAVG divides total tenant on-hand value plus outstanding dispatched transfer value by total on-hand quantity plus outstanding dispatched transfer quantity. Outstanding transfer value is the dispatch snapshot less posted receipt values, so partial receipts do not count twice. Draft, cancelled and fully received transfers are excluded. Location WAVG comes only from that location's inventory balance. WAVG is blank when quantity is zero or no balance exists; a positive quantity with zero recorded cost displays `0.0000`. No purchase price is substituted for missing inventory cost.

Dates are `YYYY-MM-DD` in the tenant timezone. Missing optional values are blank. A missing current discount is `0.00` in both discount columns. CSV quotes text, escapes quotes and prefixes formula-like cells with an apostrophe. Leading zeros remain in the CSV text, but Excel may still infer a numeric cell type when opening a CSV directly; CSV cannot guarantee spreadsheet cell typing.
